## 🛠️ إعداد بيئة العمل والتشغيل السريع

1. استنسخ المستودع:
   ```bash
   git clone https://github.com/aoodiakdiro0001-ops/studio-zerobaran.git
   cd studio-zerobaran
   ```
2. انسخ ملف المتغيرات البيئية واملأ بياناتك السرية:
   ```bash
   cp .env.example .env
   ```
3. ثبّت الاعتماديات وشغّل خادم التطوير:
   ```bash
   npm install
   npm run dev
   ```
